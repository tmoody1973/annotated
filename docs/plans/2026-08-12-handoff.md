## Extension auth — read this before debugging it

A browser extension **cannot** mint a Clerk token against a *production* Clerk instance
from `chrome-extension://`. The cookie can't be sent cross-site, Clerk falls back to an
`Authorization` header, the browser always attaches `Origin`, and production Clerk rejects
requests carrying both. Development Clerk didn't enforce it, which is why it once worked.

The fix in this repo is a **web-tab relay**: `background.ts` mints the token inside an open,
signed-in `annotated.sh` tab. **That tab must be open.**

**A "SIGN IN" label in the panel is not proof of an auth problem.** Diagnostic that settles
it fast: if a publish returns a *Convex validator* error rather than an auth error, the relay
worked and the user is authenticated.

`auth-slot.tsx` now uses the relay too (it previously used `ClerkProvider` + `syncHost`,
which could never work in production).

Clerk allowed-origins is a **separate** thing and doesn't fix the above. Extension origins
aren't editable in Clerk's dashboard — use `PATCH https://api.clerk.com/v1/instance` with
`allowed_origins`, and **merge** rather than replace or you wipe existing origins. Currently
allowed: `https://annotated.sh`, `chrome-extension://omjepfnbnljgfjlfbnkoeeiflkgledik`,
`chrome-extension://nenenpfdjkeaindoaiogleakhipggocc`.

## Landmines

- **`legacyTakeArgs` in `annotations.ts` must stay** until no installed extension sends the
  pre-rename field names. A sideloaded extension never auto-updates. Removing it breaks
  publishing for those users with `Object contains extra field commentaryText`, and they get
  no upgrade prompt. Five regression tests pin it.
- **Both key names are emitted** by `toFeedItem` / `toLandingView` (`takeText` **and**
  `commentaryText`) so the Convex and Vercel deploys stay independent. Drop the legacy keys
  only after the web app has shipped with the new names for a release.
- **Podcast clips must come from the frozen episode** (`transcripts.episodeStorageId`), never
  `sources.mp3Url` — the live enclosure is re-stitched with ads and drifts from the word
  timestamps. Commit `9cf7ac0` exists for this; a test asserts the scheduled arg.
- **Don't grep the bundle for `[0-9a-f]{64}`** to check for secrets — Clerk's
  `Web3SolanaWalletButtons` chunk has 39 ed25519 curve constants. Grep the literal token
  value, `fly.dev`, and `startThreadDev` instead.
- **`WORKER_AUTH_TOKEN` is one symmetric secret in three places** (Fly validates inbound, the
  worker authenticates *to* Convex with it, Convex validates writes). Rotating means **Convex
  first, then Fly**.
- **`apps/extension/.env.production` is gitignored and holds the real production values.**
  `plasmo build` loads it ahead of `.env`. Building from the dev `.env` ships an extension
  pointing Clerk at `http://localhost` that nobody can sign in to.

## Next work: Plan B

single-scroll side panel with **Source → Clip → Take → Published**.

dark mode, and the six real states (the panel still says "Checking Convex…" and shows a raw
video id).

It depends on Plan A's publish API, which is live. Nothing blocks it.

→ task review → fix rounds → ledger. Two things to know: **reviewers on this harness reliably
go idle without sending their verdict** — ask for it explicitly, and don't treat silence as
approval. And the reviews earned their cost: they caught an unauthenticated arbitrary-blob-
deletion path, a `.unique()` that would have permanently bricked an episode, and a missing
proxy that would have made the credential removal impossible.
